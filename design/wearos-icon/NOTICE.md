# Icon provenance

Original artwork for this unofficial, unaffiliated Immich Wear OS client. Not the official Immich
logo file - the watch-case silhouette is original, and the "dial" reuses Immich's flower motif as a
hand-redrawn vector, for identification purposes (nominative use), not as a copy of Immich's brand
mark.

extend to its name or logo (AGPLv3 ss7(e) permits withholding trademark rights independently of the
code license). No separate brand/trademark grant from the Immich project covers this artwork.
